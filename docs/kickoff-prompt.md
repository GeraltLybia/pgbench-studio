# Первый промпт для Claude Code (этап 0)

Прочитай CLAUDE.md и документ docs/architecture.pdf целиком, затем посмотри макеты в docs/design/.

Сейчас делаем только «Этап 0. Каркас» из раздела «План реализации».

1. Сначала составь план этапа: какие файлы и каталоги создашь, какие зависимости поставишь, как будешь проверять каждый критерий приёмки. Покажи план и дождись моего подтверждения.
2. После подтверждения реализуй этап. Структура каталогов — как в разделах «Бэкенд → Структура» и «Фронтенд → Структура», создавай только то, что нужно этому этапу.
3. Закончив, заполни раздел «Команды» в CLAUDE.md и пройди по каждому критерию приёмки этапа 0: что сделано и как проверено (вывод тестов, линтеров, `docker compose ps` с healthy-статусами).

Если в документе чего-то не хватает для решения — спроси, не додумывай.
